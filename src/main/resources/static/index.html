How the guard decides

Six checks, all of which fail closed.
  1. Only jobs above the score threshold, never a skip verdict.
  2. A daily cap, and never the same job twice.
  3. The whole form is read and planned before a key is pressed.
  4. Only facts you have stated get typed — never a generated answer.
  5. Any required field it cannot answer abandons the whole application.
  6. Nothing is submitted at all unless live mode is switched on.
